## Confirmed defects — ALL FIXED at `2e93291`

1. **[MEDIUM] Menu box click could never close the open popup**
   (menu_element.rs). gpui dispatches the popup's `on_mouse_down_out` in the
   CAPTURE phase (Open→Closed) and the box's `on_mouse_down` in the BUBBLE
   phase of the same click (toggle on the now-Closed state → Open): net
   re-open on every box click, the ▴ chevron advertising a close that never
   fired. Confirmed 3×3 against the pinned gpui dispatch source (rev
   1d217ee). **Fix:** the box decides from the render-time `open` snapshot
   (`was_open → Closed`, else toggle); composed-double-fire semantics pinned
   by `diw_ac07_composed_box_click_closes_after_capture_click_away`; all
   three click cases traced (box-while-open → Closed; box-while-closed →
   Open; elsewhere-while-open → Closed).
2. **[HIGH] diw-ac17's reload gate had no test through the PRODUCTION
   `ChromeSnapshot::capture`** — every divergence test ran on hand-built
   struct literals; a dead capture wire would have passed all 950 tests (the
   exact vacuous-test class this repo's history warns about). **Fix:** the
   reload-gate snapshot test now asserts the exact production `snap.widgets`
   tuple from a real `MenuPlacement`, and
   `diw_ac17_production_capture_options_edit_gates_widget_slice` builds three
   `run_pipeline` snapshots (launch / identical control / options-only edit)
   asserting None-divergence on identical and the production reason string on
   the edit.
3. **[MEDIUM] `diw_ac08_same_value_pick_no_requery` could not fail** — in the
   empty-plots fixture its assertions held whether or not a spurious dispatch
   occurred. **Fix:** batch-object identity via `Arc::ptr_eq` on a held
   `ArrayRef` clone (absorb swaps the RecordBatch only on real dispatch),
   with an in-test sensitivity control: a different-value pick must move the
   pointer and change 2→1 rows.
4. **[LOW] Layout sizing keyed on the options bag, not the kind** — an
   `input: slider` carrying stray `style: radio` + `options:` (inert on main)
   would have received a radio-tall rect. **Fix:** `input_widget_height`
   early-returns for kind ≠ Menu; pinned by
   `diw_ac05_non_menu_kind_ignores_style_keys` (slider stays 200×32).
5. **[LOW] Non-string `style:` arm untested** — its degrade-reason push could
   be deleted silently. **Fix:** `("style", Integer(1))` fixture asserting
   MenuStyle::Menu + exactly one surfaced reason.
