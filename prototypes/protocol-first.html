Opening data, Protocol first

A Protocol is what Brightfield opens and keeps. Data files, folders and databases are sources you add to it, through a keyboard-driven sources browser. Drive the cases below and watch what the window, the front door, the source library and the disk say after each one. A throwaway prototype: the data is invented and nothing touches your disk.

How: pick a scenario and press its highlighted step, or do the same thing yourself. In the sources browser the keys work: j k move, h l go up and into folders, Tab switches columns, Space marks a file, / types a glob, g t fills the browser with the preview, v switches a folder's preview between the dovetail canvas and its file list, Enter adds, Esc closes. A opens the browser from a Protocol.

Calls made in this prototype that you haven't decided
  • Dragging a folder onto Brightfield makes a Protocol named after the folder and opens the browser on that folder, so you can accept joins before anything is added.
  • A new Protocol from the front door starts as "Untitled" and takes the name of the first thing you add, while it has never run, so arc has no database to rebuild.
  • A glob comes in as one grouped row on the spine rather than one row per file.
  • Locating a moved file repoints the library entry, so every Protocol that uses it follows.
  • Opening Brightfield again restores the Protocol you had open, as macOS restores windows. Closing the window shows the front door.
  • The row count for a glob fills in after the file count, because counting rows means reading every file.
