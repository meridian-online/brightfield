### [LOW] Wildcard arms in tree walkers skip HSpace, VSpace, Legend
**Category:** edge-case
**Description:** Six tree-walking functions (`collect_as_names`, `validate_filter_by_in`, `validate_interactor_bindings_in`, `collect_selection_subscribers`, `collect_interactor_bindings`, and the existing `collect_dag_edges`) use `_ => {}` to skip unmatched Component variants. Currently this covers HSpace, VSpace, and Legend -- all leaf nodes without filterBy or interactor children. If a future Component variant with children were added, the wildcard would silently skip it.
**Evidence:** `Component` enum at ast.rs:235-254 has 9 variants. Walkers explicitly match Plot, HConcat, VConcat, Mark, Interactor, Input and wildcard the rest.
**Recommendation:** Acceptable for now. The vendored corpus gate (ac-10) catches false negatives from skipped variants. Consider converting to exhaustive matches if the enum grows.

### [INFO] Self-loop DAG fix is a bonus improvement to card 0005's code
**Category:** bug
**Description:** The diff includes a fix to `collect_dag_edges` (card 0005's code) that skips self-referential edges where `filter_by == as_param` on the same input widget. This prevents false cycle detection on specs like wnba-shots.yaml. The fix is documented as a detour in progress.md and is sound -- a widget filtering itself by the selection it contributes to is valid Mosaic.
**Evidence:** Diff lines 9-37 in analysis.rs. The guard `if source.0 != target.0` is applied to both `filter_by` and `options` edge collection paths.
**Recommendation:** No action needed. This is a legitimate bugfix discovered during corpus validation.

### [INFO] Implicit selection collection handles the Mosaic convention correctly
**Category:** edge-case
**Description:** `collect_as_bound_names` correctly identifies params created implicitly by interactor `as:` and input `as_param` bindings. This is essential for avoiding false positives on vendored specs where selections are not declared in `params:` but created by interactors. The implementation walks Plot, HConcat, VConcat, Interactor, and Input variants.
**Evidence:** The vendored corpus test (cfs_ac10) passes all 54+ specs, confirming no false positives from the implicit-selection logic.
**Recommendation:** No action needed.
